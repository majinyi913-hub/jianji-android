# 简记 1.2.0 验证报告

## 功能与兼容

- 首次使用必须初始化目前余额后才能记账；输入 0 也视为已初始化，支持负余额。
- 首页和“我的”显示目前存款，按全部账目重算，独立于所选月份和分类筛选。
- 余额初始化会吸收全部历史净收支，避免对已存在的账目重复计入；新增、改金额、改收支类型、删除、补记和去重导入均由同一净收支计算反映。
- 余额起点保存在 SQLite 中；初始化和校准不产生收支记录，不影响月度统计。
- 数据库版本 3，通过新增余额设置表兼容版本 1、2，保留账目、细分及预算。
- JSON 备份格式版本 3，事务快照包含账目、预算与余额起点，兼容旧版备份。尚未初始化时可从备份恢复余额；已有余额时合并导入保留本机起点。

## 安装包

- `JianJi-1.2.0.apk`；应用标识 `cn.jianji.app`；versionCode 3。
- Android 8.0 / API 26 及以上，目标 API 35，无新增权限。

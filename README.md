# 简记 Android 记账 App 1.3.0

中文离线记账应用，原生 Android / Java / SQLite，无第三方运行时依赖，无广告、账号或联网权限。

**[下载简记 1.3.0 APK](https://github.com/majinyi913-hub/jianji-android/raw/refs/heads/main/downloads/JianJi-1.3.0.apk)** · [版本说明](docs/RELEASE-1.3.0.md) · [SHA-256 校验文件](deliverables/SHA256-1.3.0.txt)

## 功能

- 支出和收入：金额、分类、日期、备注；支持修改、删除和未保存内容提醒。
- 首次使用先初始化目前余额（支持 0 和负数）；首页及“我的”显示目前存款，新增、修改或删除收支后自动重算。
- 已有账目会计入余额起点，初始化时不会重复加减；可校准当前实际余额，不产生额外收支。
- 餐饮细分：早餐、午餐、晚餐、饮用水、额外支出，均归入所选记账日期。
- 交通细分：电动车充电、地铁、高铁、公交、网约车、出租车、共享单车、加油、停车、飞机、普铁、其他出行。
- 购物细分：日用品、赛车模拟器、钓鱼、电动车、摩托车、数码产品、服饰鞋包、其他购物。
- 移除“居家”选项，原有居家账目归入“其他支出”，金额和余额保留。
- 每个支出一级分类均有“每月订阅服务”；在“自动订阅”中设置名称、金额、扣费日、首次月份，支持修改和删除。
- 明细与统计可切换“全部来源 / 订阅扣费 / 自动订阅”，跨一级分类单独统计每月订阅费用。
- 月度明细：月份切换、关键词搜索、收支筛选、每日结余、月收入/支出/结余。
- 分类统计：收入/支出分类金额、占比、进度条、日均支出。
- 明细和统计支持按主分类、细分分类筛选；支持查看“未细分”的旧记录，从统计跳转到对应明细。
- 分类卡片的文字水平、垂直居中，长标签支持换行和字号适配。
- 每月预算：预算进度、剩余金额、超支提示。
- 文件备份：JSON 导出/合并恢复（记录、预算、余额、订阅及进度）；CSV 导出全部记录和记账来源，Excel 可读。
- 所有金额以整数分存储。导入先校验全部内容，再使用数据库事务合并；重复 ID 跳过，已有预算保留。

## 安装

点击上方 APK 下载链接，或在仓库的 `downloads/` 目录找到 `JianJi-1.3.0.apk`，传到 Android 8.0 或更高版本的手机后点击安装。按系统提示允许当前文件管理器或浏览器安装此 APK。自行构建的安装包会输出到 `deliverables/`。

已安装旧版的手机可以直接覆盖升级：应用标识和签名保持一致，versionCode 升为 4，SQLite 数据库升级为版本 4。旧记录、预算和已初始化余额保留，旧“居家”记录改归“其他支出”。更早版本尚未初始化余额的用户仍需先填写目前余额。

这是直接安装的独立签名包，不依赖应用商店。支持 ARM、ARM64、x86、x86_64（不包含与 CPU 架构绑定的原生库）。

## 数据

数据仅保存在应用私有 SQLite 数据库内。卸载或清除应用数据会删除账本；请定期在“我的 → 导出备份”保存 JSON 文件。CSV 用于查看与分析，不用于恢复。JSON 文件未加密，请自行妥善保存。

导入支持单个 64 MB 以内、最多 100,000 笔记录的简记 JSON 备份。已有同 ID 记录和同月份预算保持原值。货币为人民币，金额支持 0.01～99,999,999.99 元，日期范围为 1900～2100 年。

新版 JSON 备份使用格式版本 4，包含细分、余额、订阅计划、扣费进度和删除状态，兼容格式版本 1～3。CSV 包含细分、记账来源和订阅扣费月份。普通记录的细分选项可留空。

## 自动订阅

底部“自动订阅 → 新增自动订阅”，或记一笔时选择某个支出一级分类下的“每月订阅服务 → 设置自动订阅”。设置服务名称、每月金额、1～31 日的扣费日和首次扣费月份。设置页面会显示即将补记的笔数与金额。

到期生成本机支出记录并更新存款。29～31 日遇到较短月份时按当月最后一天记账，之后月份仍使用原扣费日。已经开始的订阅保留起始月份，修改金额或扣费日应用于尚未记账的月份。删除订阅会停止后续记账，已发生的费用保留。

后台使用 Android 的非精确闹钟，在重启、应用更新、系统日期或时区改变后重新安排。系统省电和强行停止可能延后后台运行，打开 App 时会补记到期月份；每次最多补记 1,000 笔，积压任务会分批继续。同一订阅每月使用固定记录标识，并在同一事务中推进进度，重复运行不会重复扣费。删除历史扣费后不会自动重新生成该笔。[Android 闹钟机制](https://developer.android.com/develop/background-work/services/alarms)

“订阅扣费”筛选包含标为每月订阅服务的记录；“自动订阅”筛选只包含计划自动生成的记录。月份筛选依据实际记账日期。备份保留扣费进度与订阅停止状态；合并导入时，已有订阅设置、进度和删除状态保持本机原值。

## 余额计算

首次初始化先读取全部已有账目的收入减支出，将“实际余额－已有净收支”保存为固定起点。之后的目前存款等于“固定起点＋全部净收支”，因此新增、补记、修改金额、改变收支类型、删除、去重导入都会反映在余额中。切换月份或明细筛选不改变目前存款。初始化和校准不产生收支记录，也不影响月度收支统计。

零余额与尚未初始化是两个独立状态；退出后再次打开不会要求已初始化用户重新填写。余额可填负数，用于记录透支。首页或“我的”中的存款卡片可校准实际余额。

首次页面可以“从已有备份恢复”：版本 3 / 4 备份会恢复记录与余额起点；版本 1 / 2 备份没有余额，导入后仍需手动初始化。已有余额时合并导入，会保留本机余额起点，新加入的收支计入目前存款，重复记录跳过。备份会在数据库事务中一次性读取，恢复也会原子提交。

## 构建（Windows PowerShell 7）

```powershell
pwsh -File setup-tools.ps1
pwsh -File build.ps1
```

脚本使用微软 OpenJDK 21、Android SDK Platform 35、Build Tools 35.0.0。首次准备需要联网下载官方工具；之后构建可离线执行。构建链为 AAPT2 → javac → D8 → zipalign → apksigner。构建时会自动运行金额、汇总、日期、校验和 CSV 测试，并检查 APK 签名与 ZIP 对齐。

本版原有 114 项收支检查、新增 2,488 项订阅与日期检查通过，其中包含 1900～2100 年共 2,412 个月的月末日期检查。`python tests/test_database_migration.py` 执行 15 项桌面 SQLite 检查，覆盖升级、余额、删除、去重和事务一致性。Android 自动检查源码已编译，尚未完成设备运行、后台闹钟和视觉验证，详见交付目录的版本验证报告。

`signing/jianji-release.p12` 和 `signing/release.json` 为本次生成的更新签名密钥及密码配置，已从 Git 排除。请保留这两个文件；将来需要使用同一密钥签名，才能在不卸载的情况下覆盖升级。不要公开上传密钥。

另提供 Android Studio Gradle 项目配置（AGP 8.7.3，需 Gradle 8.9 / JDK 17+）。通过 Android Studio 打开根目录即可导入；交付包由上述 PowerShell 脚本构建及签名。

官方工具文档：[命令行构建与签名](https://developer.android.com/build/building-cmdline)、[AAPT2](https://developer.android.com/tools/aapt2)、[微软 OpenJDK](https://learn.microsoft.com/java/openjdk/download)。

# 简记 1.3.0

- 移除居家一级选项；旧居家账目保留，归入其他支出。
- 购物增加日用品、赛车模拟器、钓鱼、电动车、摩托车、数码产品、服饰鞋包、其他购物。
- 每个支出一级分类增加每月订阅服务，底部新增自动订阅管理入口。
- 支持服务名称、每月金额、扣费日与首次月份；可编辑、删除订阅。
- 到期生成支出并更新存款；短月份按月末记账，重复运行不重复扣费。
- 删除计划停止后续记账，保留历史费用；删除某笔历史扣费后不会自动重建。
- 统计和明细可单独查看订阅扣费或自动订阅，也可继续筛选月份及主分类。
- JSON 备份包含订阅、执行进度及停止状态，兼容旧版备份；CSV 增加记账来源和订阅扣费月份。

下载 `downloads/JianJi-1.3.0.apk`，Android 8.0 及以上可安装，旧版可直接覆盖升级。校验文件、安装说明和验证报告位于 `deliverables/`。

自动订阅为本机自动记账。系统可能延后后台任务，打开 App 会补记到期月份。已通过收支、订阅日期和桌面 SQLite 检查；尚未完成 Android 设备运行、后台闹钟及视觉验证。

# 简记 1.3.1

- 首页“本月结余”右侧新增“当月储蓄率”，随所选月份及账目更新。
- 储蓄率 =（本月收入 − 本月支出）÷ 本月收入 × 100%，四舍五入保留一位小数；超支显示负值。
- 当月没有收入时显示“—”，并提示暂不计算。点击储蓄率可以查看完整数值和计算说明。
- 储蓄率包含当月全部收支，包括已记账的订阅费用；明细筛选、初始余额和余额校准不影响该指标。

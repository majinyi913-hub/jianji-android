# 简记 1.2.0

中文离线 Android 记账 App，支持 Android 8.0 及以上。

## 本版功能

- 首次打开初始化目前余额，支持 0 和负数。
- 首页显示目前存款，新增、修改、删除收支后自动重算。
- 升级时已有账目保留，初始化余额不会重复计入旧收支。
- 收入、支出、分类、日期、备注、月度预算、搜索与分类筛选。
- 餐饮细分为早餐、午餐、晚餐、饮用水、额外支出；交通含电动车充电、地铁、高铁等 12 项细分。
- 分类统计及明细可按主分类和细分筛选。
- JSON 备份恢复包含账目、预算和余额；支持导入旧版备份，CSV 可用表格软件查看。

## 下载与安装

下载本次 Release 附件中的 `JianJi-1.2.0.apk`，传到手机后打开安装。已有旧版可直接覆盖安装。升级后第一次打开，请输入现在的实际余额。

`SHA256-1.2.0.txt` 可用于检查 APK 文件完整性；安装说明、验证报告及源码 ZIP 也作为附件提供。
